Create Extension Icons

Instructions

This page helps you generate the required PNG icons for the Chrome extension.

Below is the SVG icon. Right-click on each icon and select "Save image as..." to save them with the correct names.

  1. Save the 16x16 icon as icon16.png
  2. Save the 48x48 icon as icon48.png
  3. Save the 128x128 icon as icon128.png

Place all icons in the "images" folder of your extension.
