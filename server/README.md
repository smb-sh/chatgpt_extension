# سرور همگام‌سازی سشن

این سرور برای همگام‌سازی سشن‌ها بین کاربران مختلف اکستنشن Session Synchronizer طراحی شده است.

## راه‌اندازی سرور

### نیازمندی‌ها

- پایتون 3.6 یا بالاتر
- Flask
- Flask-CORS

### نصب و راه‌اندازی

1. نصب پکیج‌های مورد نیاز:

```bash
pip install -r requirements.txt
```

2. اجرای سرور:

```bash
python server.py
```

سرور به صورت پیش‌فرض روی پورت 3000 شروع به کار می‌کند. برای تغییر پورت می‌توانید متغیر محیطی `PORT` را تنظیم کنید.

## نکات امنیتی

- این سرور برای استفاده در محیط توسعه طراحی شده است. برای استفاده در محیط تولید، باید موارد امنیتی بیشتری را در نظر بگیرید.
- داده‌ها در حافظه ذخیره می‌شوند و با راه‌اندازی مجدد سرور از بین می‌روند. برای استفاده در محیط تولید باید از یک پایگاه داده استفاده کنید.
- سرور با HTTPS محافظت نمی‌شود. برای محیط تولید، حتماً از HTTPS استفاده کنید.

## نحوه استفاده با اکستنشن

1. سرور را روی یک سیستم با آدرس IP قابل دسترس از اینترنت راه‌اندازی کنید.
2. آدرس سرور را در اکستنشن وارد کنید، مثلاً: `http://your-server-ip:3000`
3. اکستنشن به صورت خودکار به سرور متصل شده و سشن‌ها را همگام‌سازی می‌کند.

## API‌های سرور

### 1. دریافت سشن‌های یک دامنه
- **URL**: `/api/sessions/<domain>`
- **Method**: `GET`
- **پاسخ**: `{ "cookies": [...], "lastUpdated": "timestamp" }`

### 2. به‌روزرسانی سشن‌های یک دامنه
- **URL**: `/api/sessions/<domain>`
- **Method**: `POST`
- **بدنه درخواست**: `{ "cookies": [...] }`
- **پاسخ**: `{ "success": true, "message": "Session updated successfully" }`

### 3. بررسی وضعیت سرور
- **URL**: `/api/status`
- **Method**: `GET`
- **پاسخ**: `{ "status": "online", "domains": [...] }`
